# Prompts de IA usados

**Obligatorio según el enunciado:** los prompts usados con IA deben estar en GitHub y compartirse con el profesor.

Cómo hacerlo (para no tener que recordarlo todo al final):

- Un fichero por persona y semana: `vlad_semana1.md`, `abde_semana1.md`, ...
- Para cada prompt: fecha · herramienta (Claude, ChatGPT, Copilot...) · el prompt · para qué se usó
  y qué se cambió después.

Recordad: en la defensa hay que saber explicar **cada línea** del código.
